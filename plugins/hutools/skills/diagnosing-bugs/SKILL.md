# diagnosing-bugs

每次启用本技能时，主代理立即向用户报告技能全名和用途；子代理立即报给经理，由经理转达。

先读[共同规则](../hutools/references/rules.md)及[分析流程](../hutools/references/analysis.md)。核对准确现象、预期、时间、输入版本和环境；先判断实际影响再设调查范围。

有安全可用的复现方式就优先复现和缩小场景；无实车/现场访问也可以基于代码和日志形成明确标为推断的候选。不得因没有快速复现而拒绝所有有用分析。

按证据排序候选原因，为每个重要候选写可区分的预测；不要强制凑 3～5 个。一次改变一个分析变量，优先只读证据与现有安全检查；插探针、改源码、安装或加压运行必须符合版本能力和授权。

反复尝试没有新证据就停止。不要默认跑 100 次/1000 次压力循环，不为几个毫秒的观察项追求漂亮统计。

输出首要判断、关键证据、反证、推荐修复与必要验证；根因未闭合时给最小补证。脱敏展示，原始日志保持不变；不自动清理“临时”资产。
