# domain-modeling

每次启用本技能时，主代理立即向用户报告技能全名和用途；子代理立即报给经理，由经理转达。

先读[共同规则](../hutools/references/rules.md)。优先查工程术语表和相关源码，沿用有效名称；用实际例子区分同词异义，说明冲突后由用户决定。

术语表只写定义与关系，流程和项目约定留其原入口。只在实际产生定义时更新，不自动改名 CONTEXT/GLOSSARY 或创建整套 ADR 目录。

难回退、未来读者难理解且存在真实取舍的决定才单列 ADR；记录上下文、已选方案、原因、代价及状态。其余复用现有设计记录。改变决定时保留旧理由和日期。

未经核实的模型写成候选，不让漂亮名词代替业务事实。

来源与适配见[声明](../../THIRD_PARTY_NOTICES.md)。
