# grilling

每次启用本技能时，主代理立即向用户报告技能全名和用途；子代理立即报给经理，由经理转达。

先读[共同规则](../hutools/references/rules.md)。把目标、约束、假设和待决事项组织成依赖关系；只问前提已经具备的问题，不让用户决定尚未调查的事实。

每轮通常 1～3 个问题，优先使用宿主中途填写卡片。每个选择给推荐和决定性理由；没有真实取舍不凑选项。事实可从工程或原始来源获得时先调查。

用户答复后更新对应决定，不推翻无关已确认项。调查与提问按实际问题影响设停止条件；需求、方案与必要验收已有共同理解就结束访谈，不穷尽假想边界。

一般想法或单个技术问题可在对话中讨论。只要任务形成工程设计，就用 [grill-with-docs](../grill-with-docs/SKILL.md) 将决定写入用户可独立评审的方案；用户明确要求只在聊天中回答时沿用其选择。
