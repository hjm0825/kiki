# 按需分工与交接

职责固定，实例按需；经理唯一派工并整合任务状态。小型低风险工作直接处理，复杂、跨模块及正式交付使用原生子代理并保持必要独立审查。岗位手册必须实际读入任务，文件存在或角色名不同不证明已加载/独立。

| 职责 | 任务与输出 | 边界 |
| --- | --- | --- |
| 经理 | 整理需求、纵向拆批、提出方案、记录批准范围/依赖、整合最终状态 | 不以进度覆盖失败，不越过用户决定权 |
| 开发 | 查真实消费者，在批准范围实施、单测、修复，返回差异/证据 | 不自改验收/接口/权限，不覆盖其他写入者 |
| 测试 | 实现前提出验收实例/反例，查红态，独立验证最终组合和必要集成/E2E | 不在夹具补被测能力，不把隔离测试当真实集成 |
| 资料管理 | 按[资料流程](materials.md)维护导航/来源/摘要，提出精确清单 | 不按名称/年龄删除，不另立重复状态 |
| 协作观察 | 按[监督流程](observation.md)查阻塞、重复投入及违规，暂停并追踪解除 | 无改规则/重新派工权，异步提醒不是事前拦截 |
| 独立 reviewer（按风险承担审查职责） | 从需求、最终差异和原始证据找遗漏及反例，说明覆盖边界 | 不复述作者 PASS，由不同于该改动实现者的实例执行 |

独立审查不强制新增常驻岗位。无子代理时经理可完成允许工作并注明；需独立审查的交付保留待审，不能扮演两身份冒充。

## 派工最小包

给 run/task 标识、阶段/角色/实例、目标及非目标、需求/批准方案/规则/源码版本、输入和证据位置、可写文件/保护范围、共享资源所有者、依赖、产物/返回格式、预算和停止条件。参考[任务字段](../assets/task.md)，不复制整份历史聊天；只读任务明确不能修复。

不同事实调查可并行，共享文件/运行资源默认单一所有者。隔离 worktree/目录先核对来源和授权，不为并行重置已有工作。worker 可围绕事实有限沟通，依赖/结论变化同步经理，不自行扩大任务。

返回实际使用版本、发现/证据、具体改动、命令/结果、产物、未决项及主要工作片段。经理核对矛盾和范围再整合，摘要不替代原始验证。

## 暂停与重派

需求变化、共享冲突或保护失效时暂停相关写入；观察员发现违规可请求宿主中断并立即通知经理。中断调用不代表子进程已退出：核查 worker 和工具会话/进程，不能观察则标未知并保持对应写入禁令。确认不再写入且有检查点后重派；暂停不自动回滚或终止无关任务。

解除时核对原因、措施、批准范围和证据版本；实质争议交用户决定。误报用事实解除并留理由，不无限互相否决。
