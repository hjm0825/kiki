# 交互和接入

## 选择与填写

选择题短而互斥，推荐项先列；保留自由回答。路径、现象、时间可合并为至多三个相关问题。卡片不负责上传附件、输入密码或代替系统权限弹窗；附件走宿主入口，凭据走正规认证。

不要用“再确认已确认内容”的卡片演示功能。有实质选择才提问。必需问题没答时保持待答，不结束成已完成；普通偏好可按已说明的可逆默认值推进，但不能推断授权。收到异步答案只重开受影响步骤，不重新问整套问题。

## 工程事实

先从当前用户输入、项目规则和已有任务记录识别根、所属项目、源码/资料/报告入口。核对 Git 版本和未提交状态、路径真实位置及可读性。报告所在工程和被分析工程可能不同，明确各自归属。

路径未知只询问必要位置，不搜索整台电脑。确认后只读所需目录。新项目缺少入口时建议一个清楚的报告位置并确认；报告路径不得覆盖源码或原始输入。已有工程约定直接沿用。

把任务目标、已确认输入、授权范围、进行中问题和下一步记录在同一任务文档。参考[接入字段](../assets/project-context.md)，只填本任务用到的内容；不把模板复制成每项目必备的整套目录。

## 接续

启动时如有任务记录，核对状态与现场后继续。卡片取消只结束该问题等待；不自动取消整个项目，也不按推荐选项开始有副作用的工作。发现输入改变时重新核对对应结论，旧证据保留并注明适用版本。
