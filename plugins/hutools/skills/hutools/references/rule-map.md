# 需求到执行入口

这是既定需求的导航与验收视图，不是第二份规则或运行通过声明。实际版本/覆盖结论在任务记录给出。

| 决定 | 执行入口 | 行为证据 |
| --- | --- | --- |
| Q1/Q12/Q26 跨工程与插件 | [接入](intake.md)、[入口](../SKILL.md) | 无工程治理文件可接入、资料库确认、包内依赖、原目录不存在恢复；跨机器另记 |
| Q2、D04/D09/D12 职责 | [分工](roles.md) | 实际加载、必要独立实例/交接，小任务不固定全员 |
| Q3/Q10/Q17 研发测试 | [开发](development.md)、[TDD](../../tdd/SKILL.md) | 真实红绿、遗留特征测试、配置/文档例外、最终真实组合 |
| Q4、D05/D13 确认变化 | [规则](rules.md)、[分工](roles.md) | 明确批次批准、只停相关任务、重派前停写、旧证据重审 |
| Q5/Q8 生命周期 | [资料](materials.md) | 精确授权、未知资产保留、归档核验、失败与恢复 |
| Q6 分层 | [包导航](../../../AGENTS.md)、[规则](rules.md) | 规则唯一，项目事实分开，不覆盖有效治理 |
| Q7/Q22 保护/关联 | [规则](rules.md)、[任务字段](../assets/task.md) | 真实拒绝及绕过边界、失效停止、版本失配/缺测/失败不能完成 |
| Q9、D16 版本 | [规则](rules.md)、[复盘](observation.md) | 升级批准、切换留痕、回退保护资产 |
| Q11 争议 | [开发](development.md)、[分工](roles.md) | 原始证据裁决，不自改预期 |
| Q13/Q14/Q19 架构部署 | [设计](../../codebase-design/SKILL.md)、[开发](development.md) | 所有者/消费者/旧新组合，主体和现场分开，最小取证 |
| Q15/Q16/Q24、D17 观察 | [观察](observation.md)、[规则](rules.md) | 阻塞/违规/误报解除，真实片段、重试累计、等待去重、有界核查 |
| Q18、D15 试行 | [开发](development.md)、[分工](roles.md) | 隔离正常/反例、暂停恢复后，获批真实小批；样例不冒充收益 |
| Q20 可读性 | [规则](rules.md)、[审查](../../code-review/SKILL.md) | 具体阅读问题、单位/副作用，不按行数/注释率无限返工 |
| Q21 自包含 | [入口](../SKILL.md)及各技能 | 9 技能按需加载，来源许可固定，无需另装同名技能 |
| Q23/Q25、D10 事实建议 | [调研](../../research/SKILL.md)、[规则](rules.md) | 适用原始依据，事实/推断分开，缺关键依据先补查 |
| 第七轮 Git/报告 | [规则](rules.md)、[任务字段](../assets/task.md) | 差异/证据真实，精确提交，不混暂存区，不默认 push |

D01 Codex 范围、D02/D03 质量与追溯优先、D07 轻量概览/相关链路深入、D08 真实上下游集成贯穿以上入口。旧 D06 仅讨论及旧 D14 三角色属历史阶段，现按获批执行范围和五职责处理；后续专项候选不是首版必装依赖。
