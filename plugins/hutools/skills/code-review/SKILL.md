# code-review

每次启用本技能时，主代理立即向用户报告技能全名和用途；子代理立即报给经理，由经理转达。

先读[共同规则](../hutools/references/rules.md)。从任务记录确定批准范围、基线和规范；缺关键依据先补查，不强制接入线上任务系统。

检查真实批次：已提交差异、暂存区、工作树、相关未跟踪文件和子仓指针，不只比较基线到 HEAD。尊重已有用户修改，不假定全部差异属于本批。

分别评估需求满足与可读性/架构规范，反馈定位文件和行为，说明影响与建议。核心问题阻塞相关交付，主观风格建议不无限打回；工具能确定的格式问题交既有检查。

验证证据应对应最终版本、配置和消费者；失败/边界检查按实际风险。独立审查按复杂度和风险启用，不固定每次两个 agent；无独立执行者则如实记录。

review 只读，不顺手修改或提交。输出首要发现及推荐动作，已有充分证据就结束，不把所有代码气味强制转成重构任务。
