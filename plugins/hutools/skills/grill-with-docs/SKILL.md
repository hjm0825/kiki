# grill-with-docs

先读[共同规则](../hutools/references/rules.md)。使用 [grilling](../grilling/SKILL.md) 澄清当前可决定的问题；存在术语歧义时使用 [domain-modeling](../domain-modeling/SKILL.md)。

复用已有需求、设计和任务入口，区分用户确认、团队建议和未决项。把关键决定、理由、证据和下一步及时落盘，不为每轮对话建文档。

用户已明确的细节直接采用，不重复确认；新增实质取舍用中途卡片询问并给推荐。事实调查由团队完成，不让用户转录可读资料。讨论完成后按[研发流程](../hutools/references/development.md)进入已批准具体批次的实施与验收；未批准时保留待决项，不提前修改源码。

来源与适配见[声明](../../THIRD_PARTY_NOTICES.md)。
