版本：0.1.0-preview.1。目标分支：hutools。日期：2026-11-17。

## 这一版提供什么

经理入口及开发讨论/问题分析/咨询三分支；处理中选择/填写指引；五类职责的按需分工；八项方法技能的本地适配；中文问题报告和任务记录模板；分发包检查工具。

分析路径可读取材料、形成根因判断与方案、写入约定报告。开发路径本版到需求、设计和验收计划为止。业务源码执行、正式角色配置、运行时强制拦截和完整研发闭环在后续批次。

## 最短客户端验收

在能访问你准备分析的本地文件、且已安装 Codex 的桌面环境中操作：

1. 按[首页安装步骤](../README.md)添加 `hutools` 分支来源，安装 HuTools 后新建对话。若命令不可用，记录客户端版本与原错误，按官方本地 marketplace 方式适配。
2. 选择 HuTools，输入“运行”。预期出现开发/分析/其他的选择卡片；填写后直接接续。
3. 选择“其他”，问一个简单工程问题。预期直接回答，不创建工程目录或空报告。
4. 新对话直接要求分析一个小问题，同时给源码、日志与报告目录。预期跳过模式选择，只补问缺少的必要信息，报告包含根因依据与推荐方案，原始输入不变。
5. 新对话讨论开发功能。预期得到需求问题和方案，预览版不改业务源码。

这是交互与产物检查，正常完成回复“完成”；失败时提供步骤编号、客户端版本及最小错误信息即可。若界面没有卡片，说明是退回文字问答，不把它记为卡片验收通过。

## 更新与恢复

通过指定 GitHub 分支发布正常提交，main 保留。安装升级按宿主插件源更新方式操作；项目报告和资料在项目中保存，不放插件缓存。回退插件版本时仍先核对当前任务约定，不删除新产生的项目材料。
