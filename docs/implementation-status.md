## 安装后的最小验收

1. 安装具体候选/发布提交后核对版本，新建对话选择 HuTools 输入“运行”。看到模式选择与资料库确认；同次已确认不重复，咨询不展开全仓历史。
2. 阅读包内 hook 说明并由用户在宿主审阅信任；未信任时记录未启用。不能用 bypass 信任参数代替这一步。
3. 在独立样例里核对实际触发、允许补丁、拒绝越界/未批准调用、策略变化及错误输入；检查沙箱对批准范围和授权文件的真实保护。
4. 如实填写受支持调用和绕过边界。无法建立关键保护时暂停对应高风险功能，保留咨询/只读调查。
5. 其他机器需要重新确认资料库和本机绑定，运行相同最小测试，不搬运凭据/全局配置。
